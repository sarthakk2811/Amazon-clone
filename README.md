# 🛒 Amazon Clone

A frontend clone of the Amazon homepage built using HTML and CSS, focusing on layout, styling, and responsiveness.

---

## 🚀 Features

- Amazon-style navigation bar with search  
- Product grid layout with categories  
- Hero section with banner  
- Footer with multiple sections  
- Responsive design for different screen sizes  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- Font Awesome  

---

## ▶️ Run Locally

1. Download or clone the repo  
2. Open `index.html` in your browser  

---

## 📌 Notes

- This is a frontend-only project (no backend functionality)  
- Built to practice layout design and UI replication
